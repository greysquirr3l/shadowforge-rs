# Suggested Development Commands

## Build
```bash
# Development build
cargo build

# Production build
cargo build --release
```

## Test
```bash
# Run all tests
cargo test

# Run specific test
cargo test <test_name>
```

## Run
```bash
# Run the application
cargo run
```

## Other Useful Commands
```bash
# Format code
cargo fmt

# Lint
cargo clippy

# Check types
cargo check
```
